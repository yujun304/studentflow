# StudentFlow 화면별 UX 결정

## 우선순위

StudentFlow는 화면의 장식보다 **설명서 없이 다음 행동을 찾을 수 있는가**를 먼저 평가합니다. 그다음으로 실제 학교에서 오래 사용한 도구처럼 보이는 자연스러움, 360px부터 가능한 반응형 접근성, 시각적 일관성을 고려했습니다.

| 화면 | 핵심 UX 결정 | 이유 |
| --- | --- | --- |
| 로그인 | 역할을 고르는 체험 선택을 입력 폼 안에 배치 | 어떤 화면을 보게 되는지 로그인 전에 이해하고, 평가자가 역할별 차이를 즉시 확인할 수 있습니다. |
| 대시보드 | 통계 카드 대신 “지금 처리할 업무”를 첫 영역에 배치 | 처음 로그인한 사용자가 30초 안에 해야 할 일을 찾게 합니다. |
| 업무 | 데스크톱은 상태별 칸반, 모바일은 상태 탭 목록 | 작은 화면에서 가로로 축소된 보드를 읽게 하지 않고, 한 상태의 업무를 집중해 처리합니다. |
| 업무 상세 | 요구사항·참고 파일·다음 행동을 가까이 배치 | 사용자가 업무를 열고 다시 목록으로 돌아가 설명을 찾지 않게 합니다. |
| 제출 | “제출물 올리기”와 “검토 요청하기”를 분리 | 버튼을 누른 뒤 어떤 결과가 생기는지 분명히 합니다. 실제 업로드가 아닌 데모라는 사실도 파일 입력 아래에 알립니다. |
| 검토 | 반려 시 사유 입력을 필수화 | “반려”만으로 끝나지 않고 학생이 무엇을 고칠지 바로 알 수 있게 합니다. |
| 공지 | 제목·대상·내용 다음에 미리보기를 제공 | 게시 전 대상과 내용이 맞는지 확인하게 해 실수를 줄입니다. |
| 행사 | 신청 인원·정원·신청 버튼을 한 모달 안에 둠 | 선착순 여부를 알아보기 위해 다른 화면을 열 필요가 없습니다. |
| 조 편성 | 이동 전에 현재 조와 이동 결과를 문장으로 안내 | 한 사람이 두 조에 배정될 수 있다는 걱정을 줄이고, 변경 효과를 예측하게 합니다. |
| 출석 | 이름 옆에 최소 40px 높이의 상태 버튼을 나란히 배치 | 모바일에서도 한 손으로 여러 학생의 출석을 연속 변경할 수 있습니다. |
| 사용자 권한 | 권한 없음 화면에 이유와 가능한 범위를 표시 | 메뉴를 숨겨 기능이 사라진 것처럼 보이는 문제를 피합니다. |
| 아카이브 | 읽기 전용 표기와 로딩·오류·빈 상태 선택기를 제공 | 과거 기록의 성격을 분명히 하고, 서버 연결 전 모든 상태를 검토할 수 있게 합니다. |

## 인터랙션 원칙

각 화면에는 가장 중요한 행동 하나만 파란색 주요 버튼으로 강조했습니다. 보조 행동은 흰 배경 테두리 버튼, 되돌리기 어려운 행동은 붉은 버튼으로 구분합니다. 상태는 색만 쓰지 않고 “검토 대기”, “수정 후 다시 제출”처럼 문장으로도 표시합니다.

저장과 처리 중 상태는 버튼 문구를 바꾸고, 완료 후에는 인라인 메시지로 바뀐 내용을 알려 줍니다. 모달은 업무 수정, 제출, 반려, 권한 변경처럼 현재 화면에서 맥락을 잃으면 안 되는 경우에만 사용했습니다. `Escape` 키와 바깥 영역 클릭으로 닫을 수 있으며, 키보드 포커스 색과 대비를 유지합니다.

## 반응형·접근성 결정

| 조건 | 구현 |
| --- | --- |
| 360px | `html` 최소 폭을 360px으로 정하고, 콘텐츠 영역은 모바일 우선 여백과 줄바꿈을 사용합니다. |
| 내비게이션 | 데스크톱은 고정 사이드바, 모바일은 상단 메뉴 시트와 자주 쓰는 5개 하단 메뉴를 함께 제공합니다. |
| 표와 칸반 | 좁은 화면에서는 표 열을 텍스트 행으로 바꾸고, 칸반은 상태 탭 목록으로 바꿉니다. |
| 터치 | 출석 상태와 주요 버튼은 최소 40px 높이를 유지합니다. |
| 모션 | 150ms 이내의 색상·변형 전환만 쓰고, `prefers-reduced-motion`에서 비필수 모션을 제거합니다. |
| 대비 | 흰 배경에 짙은 슬레이트 본문, 하나의 운영 파랑 `#2563A8`을 사용해 정보 강조와 충분한 대비를 함께 확보합니다. |

## AI 생성물처럼 보이지 않기 위한 점검

과도한 그라데이션, 유리 효과, 네온, 장식용 차트, 큰 히어로 카피, 반복적인 둥근 카드, 의미 없는 아이콘 사용을 피했습니다. 넓은 화면도 카드의 집합이 아니라 얇은 구분선과 목록 행의 문서형 리듬으로 구성했습니다. 샘플 데이터는 축제 부스, 아침 방송, 체육대회 응원 도구, 급식실 캠페인 등 실제 중학교 학생회에서 나올 법한 서로 다른 기한·담당자·상태를 사용했습니다.

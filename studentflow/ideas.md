## 선택한 방향 — 학기 운영 보드

### Design Movement

**현대적 공공 서비스 및 교육 행정 도구의 기능주의**를 따릅니다. 친숙한 문서·목록·표·상태표의 문법을 바탕으로, 매일 사용하는 도구에 필요한 안정감과 속도를 만듭니다. 화려한 제품 소개 화면이 아니라 이미 한 학기 동안 쓰인 운영 시스템처럼 보이게 합니다.

### Core Principles

1. **다음 행동 우선**: 페이지마다 가장 중요한 행동을 하나만 명확히 강조하고, 관련 맥락 바로 옆에 둡니다.
2. **상태는 말로도 전달**: 색상 외에 상태명, 기한 문구, 아이콘 아닌 텍스트 라벨을 함께 써서 누구나 빠르게 이해하게 합니다.
3. **문서 같은 밀도**: 넓게 벌어진 카드 대신 얇은 구분선, 행 단위 정보, 작은 섹션 제목을 사용해 실제 업무 내용을 충분히 보여 줍니다.
4. **작은 화면에서 우선순위 재구성**: 데스크톱 표나 칸반을 축소하지 않고, 모바일에서는 상태 탭·목록·하단 핵심 행동으로 흐름을 새로 구성합니다.

### Color Philosophy

배경은 종이와 칠판 지우개 가루처럼 아주 옅은 회색·백색으로 두어 긴 사용에도 피로가 적게 합니다. 주요 행동과 현재 위치에는 단 하나의 **안정적인 학교 파랑**만 쓰고, 경고·오류는 드물고 구체적인 상황에서만 씁니다. 색은 장식이 아니라 읽는 순서와 위험도를 알려주는 신호입니다.

### Layout Paradigm

데스크톱은 **운영 선반**처럼 좌측에 맥락과 메뉴를 고정하고, 우측의 콘텐츠를 제목·다음 행동·작업 목록의 수직 흐름으로 배치합니다. 넓은 중앙 카드 하나가 아니라 두께가 다른 정보 줄과 구분선으로 우선순위를 만듭니다. 모바일은 상단의 현재 위치와 하단의 자주 쓰는 메뉴를 기준으로, 처리 단위를 한 줄씩 끝낼 수 있게 재구성합니다.

### Signature Elements

1. 현재 메뉴와 상태를 표시하는 **옅은 파란 배경의 얇은 선택 띠**
2. 일정·마감·제출 여부를 빠르게 훑게 하는 **날짜 칩과 문장형 상태 태그**
3. 업무를 문서처럼 구분하는 **1px 회색 규칙선과 작고 선명한 섹션 레이블**

### Interaction Philosophy

행을 누르면 상세를 열고, 가장 중요한 결과 행동은 항상 명확한 동사로 표시합니다. 저빈도 기능은 보조 메뉴로 밀어두되 경로를 잃지 않게 하며, 위험한 작업은 결과를 설명한 다음 확인합니다. 클릭 피드백은 빠르고 조용해야 하며, 상태 변경 직후에는 무엇이 바뀌었는지 짧게 알려 줍니다.

### Animation

업무 도구의 집중을 해치지 않도록 애니메이션은 최소화합니다. 목록의 hover와 버튼 누름은 120–180ms의 짧은 색·위치 변화만 사용하고, 모달과 모바일 시트는 200ms 안팎의 opacity·transform 전환으로 나타납니다. 저장 완료는 이동 애니메이션 대신 인라인 상태 문구와 짧은 토스트로 알려 줍니다. `prefers-reduced-motion` 환경에서는 모든 비필수 전환을 제거합니다.

### Typography System

시스템 산세리프(`Pretendard`, `Apple SD Gothic Neo`, `Noto Sans KR`, `Segoe UI`, sans-serif)를 사용합니다. 화면 제목은 22–26px, 섹션 제목은 15–16px/700, 본문은 14–15px/1.55, 보조 문구는 최소 12px으로 설정해 중학생도 편하게 읽을 수 있게 합니다. 숫자와 날짜는 표 폭이 흔들리지 않도록 tabular figures를 사용합니다.

### Brand Essence

**학생회가 오늘의 운영 업무를 놓치지 않고 함께 끝내는, 학교 안의 실무 도구.**

성격: **차분한, 명료한, 믿을 만한**.

### Brand Voice

제목과 버튼은 실제 학교에서 쓰는 단어와 결과가 예상되는 동사를 사용합니다. 과장하거나 추상적인 표현 대신 지금 확인할 대상, 실행 결과, 다음 단계를 말합니다.

> “오늘 마감인 업무 2개가 있어요.”

> “출석을 저장하면 이번 행사 기록에 바로 반영돼요.”

### Wordmark & Logo

텍스트 로고는 `SF` 두 글자를 겹치지 않는 두 개의 간결한 문서 모서리 형태로 조합하고, 옆에 굵기 650의 StudentFlow 워드마크를 배치합니다. 아이콘은 메뉴의 장식이 아닌 맥락 보조용으로만 쓰며, 18px 선 아이콘 규격을 지킵니다.

### Signature Brand Color

**운영 파랑 `#2563A8`** — 차분하지만 링크·선택 상태·주요 행동을 구분할 만큼 선명한 파랑입니다.

## Style Decisions

- 데스크톱 내부 화면은 항상 좌측 **운영 선반**을 기본 구조로 사용한다. 운영 선반에는 StudentFlow 로고, 현재 학기, 현재 위치, 주요 운영 흐름, 사용자 역할을 지속적으로 표시한다.
- 업무와 출석은 기본적으로 카드보다 **행·표·규칙선** 중심으로 표현한다. 카드형 박스는 상태 묶음이나 즉시 처리가 필요한 예외적 단위에만 사용한다.
- StudentFlow의 `SF` 문서 모서리 심볼과 워드마크는 로그인뿐 아니라 모든 내부 화면에서 조용하게 반복한다.
- 옅은 파란 선택 띠, 왼쪽 상태선, 날짜·마감 문장형 표기, 1px 회색 규칙선을 운영 언어로 일관되게 반복한다.
